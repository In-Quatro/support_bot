Напиши полный рабочий проект Telegram-бота на Python (с использованием библиотеки aiogram v3 и асинхронной БД aiosqlite), упакованный для запуска через Docker и Docker Compose для деплоя на VPS.

### 🎯 НАЗНАЧЕНИЕ БОТА
Бот предназначен для приема заявок от пользователей в техническую поддержку (ИТ-отдел/сервисную службу) и запроса картриджей, а также для работы инженеров с этими заявками.

---

### 📋 ФУНКЦИОНАЛ И СЦЕНАРИИ

#### 1. Для пользователей (ЛС с ботом):
- **Главное меню:**
  - 📝 Создать заявку в ТП
  - 🖨 Запросить картридж
  - 📁 Мои обращения
- **Сценарий 1: Создание заявки в ТП (пошаговый опрос / FSM):**
  1. Номер поликлиники
  2. Адрес поликлиники
  3. Номер технологической точки принтера
  4. Номер кабинета
  5. IP-адрес АРМ (с валидацией формата IP)
  6. Описание проблемы
  7. Прикрепление фото (опционально, возможность пропустить или загрузить до 3-х фото)
  8. Подтверждение отправки.
  *После отправки заявка получает уникальный ID из БД (например, #1001), сохраняется в систему и отправляется в рабочий чат инженеров.*

- **Сценарий 2: Запрос отгрузки картриджей (отдельный раздел):**
  - Опрос: Номер/Адрес поликлиники, Номер кабинета, Модель принтера, Количество картриджей, Доп. комментарий.
  - Формирует отдельную заявку с типом "Картриджи" и отправляет в чат инженеров.

- **Сценарий 3: "Мои обращения":**
  - Выводит список всех обращений пользователя (ID заявки, дата, тип, текущий статус: "Новая", "В работе", "Выполнена", "Отклонена").
  - При клике на заявку показывает подробную информацию.

---

#### 2. Для инженеров (Работа в общем чате):
- Все новые заявки от пользователей "сливаются" в единый закрытый Telegram-чат инженеров.
- Каждая заявка приходит со всей структурированной информацией, прикрепленным фото и инлайн-кнопками управления:
  - 🛠 **В работу** (меняет статус в БД, меняет текст сообщения в чате и отправляет авто-уведомление пользователю: *"Ваша заявка #ID взята в работу инженером @username"*).
  - ✅ **Выполнено** (меняет статус в БД, отправляет пользователю уведомление: *"Заявка #ID выполнена. Если проблема осталась, создайте новое обращение"*).
  - ❌ **Отклонить** (запрашивает у инженера причину или отклоняет с авто-уведомлением пользователю).

### 🛠 ТЕХНИЧЕСКИЙ СТЭК И ТРЕБОВАНИЯ

1. **Язык и библиотеки:** Python 3.11+, `aiogram 3.x`, `aiosqlite` (для асинхронного SQLite).
2. **База данных (SQLite):**
   - Таблица `users` (id, telegram_id, full_name, username).
   - Таблица `tickets` (id INTEGER PRIMARY KEY AUTOINCREMENT, user_id, type, clinic_num, address, tech_point, cabinet, ip_address, description, photos_json, status, created_at, updated_at).
3. **Безопасность и хранение фото:** Файлы фото сохраняются локально в папку `./data/photos/` или хранятся через `file_id` Telegram.
4. **Конфигурация:** Все секреты (BOT_TOKEN, GROUP_CHAT_ID) должны читаться из `.env` файла через `pydantic-settings` или `python-dotenv`.
5. **Контейнеризация:**
   - Напиши `Dockerfile` (оптимизированный multi-stage или slim).
   - Напиши `docker-compose.yml` с монтированием volumes для сохранения БД (`bot_database.db`) и загруженных фото при перезапусках контейнера.
   - Добавь `.env.example` и `requirements.txt`.
